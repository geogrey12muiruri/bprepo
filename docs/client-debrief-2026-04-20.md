# Blue Pineapple Website Updates — Client Debrief
**Date:** April 20, 2026 (Nairobi)  
**Client:** Ian  
**Project:** Landing page + Fort Jesus Trip (Hop-On Hop-Off)

## Goal
Refresh the website to feel premium, modern, and fully responsive, while clearly communicating the updated **Hop‑On Hop‑Off** Fort Jesus experience (water-matatu style along the North Coast).

## What We Improved
### 1) Landing page (Home)
- Balanced mobile layout (no sideways scrolling / blank space on small screens).
- More premium feel: reduced visual noise, consistent spacing, calmer hero behavior.
- Modern section layout on large screens using responsive grid structure.

### 2) Fort Jesus Trip page
- Rebuilt the page hierarchy to emphasize **Hop‑On Hop‑Off** immediately after the hero (no longer buried).
- Removed redundant/duplicated route UI.
- Removed placeholder guest reviews to create space for clean, high-value content.
- Added a simple in-page navigation row for faster scanning (Route & Fares / Safety / Departure).

## Hop‑On Hop‑Off: What’s Now Captured (from the leaflet brief)
- Clear headline/subtitle: “Hop‑On. Hop‑Off. Your Coast.”
- Route stops (Mtwapa → Fort Jesus) presented as a modern horizontal block carousel.
- Pricing cards + pricing note (4–7 stops range + per-stop add-on after 3).
- Concessions: Children 5–15 (50% off) + Under 5 (Free).
- Timetable: depart daily, approximate arrival times, last return by 5:30 PM.
- “How it works” steps: Choose stop → Board → Pay on board.
- Launch discounts: Kenyan resident + local community discounts.
- Fare table kept compact (collapsed preview) to reduce clutter.

## Design Notes / UX Decisions
- Avoid distracting background video loops; keep motion subtle and purposeful.
- Typography standardized to match the landing page’s hierarchy.
- Keep the UI premium/dark, with controlled accent colors.
